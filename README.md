# BiteBack

**Eat Smart. Spend Less. Waste Nothing.**

BiteBack is a food-inventory and budget meal-planning web app designed for Malaysian university students. It helps users track ingredients, prioritise items that need attention, plan meals around a chosen budget, and record the estimated value of food used or wasted.

## Core features

- **Use First:** add ingredients with quantity, category, purchase date, expiry date and estimated value. Items are sorted by expiry date.
- **Budget Rescue:** request a 1–7 day meal plan with a budget in Malaysian Ringgit (RM) and optional preferences.
- **Cook What You Have:** the app can call Google Gemini when `GEMINI_API_KEY` is configured. Otherwise, or if the API response fails validation, it clearly labels its local suggestions as demo mode.
- **Waste Less, Save More:** record quantities as used or wasted and see estimated values and recent activity.
- **Accounts and data separation:** pantry records, food events, and saved meal plans are scoped to the signed-in account. New accounts receive their own starter ingredients.

## Run locally

Requires Python 3.10+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env`, optionally set the values described below, then run:

```bash
python app.py
```

Open `http://127.0.0.1:5000`.

The SQLite database is created automatically. Set `DATABASE_PATH` if you want to choose a different location. Keep `.env`, database files, and virtual environments out of public source control.

## Optional Gemini integration

1. Obtain a Gemini API key from Google AI Studio.
2. Put it in `.env` as `GEMINI_API_KEY=your_key_here`.
3. Optionally set `GEMINI_MODEL=gemini-2.5-flash`.
4. Restart the app.

The key is read from an environment variable and must never be committed to GitHub. Gemini is used only for optional meal-planning suggestions. When Gemini is unavailable for meal planning, BiteBack falls back to deterministic local suggestions and tells the user why. Gemini output is checked for the requested number of days, valid fields, and a total estimated cost that does not exceed the requested budget; invalid output is replaced by the local fallback.

## Deploy to Render

1. Push the project folder to a public GitHub repository.
2. Create a Render Web Service connected to the repository.
3. Build command: `pip install -r requirements.txt`
4. Start command: `gunicorn app:app`
5. Add `BITEBACK_SECRET_KEY` and, optionally, `GEMINI_API_KEY` and `GEMINI_MODEL` as Render environment variables.
6. For persistent SQLite storage, attach a Render persistent disk and set `DATABASE_PATH` to a path on that disk, such as `/var/data/biteback.db`.

Without persistent storage, local SQLite data may be lost when the service restarts or redeploys. Use a long, random `BITEBACK_SECRET_KEY` in any deployed environment.

## Important limitations

- Expiry dates are reminders, not proof that food is safe. Do not eat food that appears spoiled.
- Meal costs are estimates, not live grocery prices or guaranteed savings.
- The prototype does not verify nutrition, allergens, or medical dietary suitability. Users should check ingredients and adapt portions.
- The fallback meal suggestions are local demo logic, not generated by a live AI model.
- The app is a hackathon prototype; do not present estimated food value as independently verified financial or environmental impact.

## Starter pantry data

Each newly registered account currently receives five clearly editable starter items (eggs, bananas, spinach, rice, and tofu) so the dashboard and meal-planning flow are usable immediately. These are demo/example inventory records, not real purchases. Each starter record is assigned to that account only. Users can edit or delete these items and add their own ingredients.

## Account data and meal-plan validation

Pantry reads, edits, deletions, use/waste events, statistics, and meal-plan history are scoped to the authenticated account. Meal-plan requests accept a budget from RM 0 to RM 1,000 and a whole-number duration from 1 to 7 days. Gemini output is rejected if its day count or cost totals fail validation; the app then labels and returns local demo suggestions. Local estimates are illustrative and are not live market prices.
